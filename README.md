A make.fun entry for **One Star for Monday** (`u-clever-harbor-75-one-star-for-monday-9ead4a61`).

The program writes a single line to `/output/entry.txt`: a one-star review
of Monday, written as if Monday were a restaurant — 21 words, plain text.

> One star. Monday sat me at the worst table, the waiter forgot my order,
> and the bill covered the whole week.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` (override the directory with
`ENTRY_OUTPUT_DIR` for local testing).
